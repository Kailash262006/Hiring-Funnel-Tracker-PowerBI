# 📊 Hiring Funnel Tracker Dashboard (Power BI)

## 📌 Project Overview

The Hiring Funnel Tracker Dashboard is a Power BI project designed to analyze and monitor recruitment performance across different stages of the hiring process.

This dashboard helps HR teams and recruiters track candidate progression, evaluate recruiter performance, measure hiring efficiency, analyze recruitment sources, and optimize hiring costs through interactive visualizations and KPI-driven insights.

---

## 🎯 Business Objective

The primary objective of this project is to:

* Monitor candidate movement through the hiring funnel
* Measure recruitment effectiveness
* Identify top-performing recruiters
* Evaluate hiring source performance
* Analyze hiring costs and efficiency
* Support data-driven recruitment decisions

---

## 🛠️ Tools & Technologies Used

* Power BI Desktop
* Power Query
* DAX (Data Analysis Expressions)
* Microsoft Excel

---

## 📂 Dataset Structure

The project uses a star schema data model consisting of the following tables:

### Candidates

Contains candidate-level hiring information.

### Recruiters

Contains recruiter details such as experience level and region.

### Jobs

Contains job opening information including role, department, location, and priority.

### Calendar

Date dimension table used for time-based analysis.

---

## 📊 Dashboard Pages

### 1️⃣ Hiring Overview

Provides a high-level summary of recruitment activities.

#### KPIs

* Total Applicants
* Shortlisted Candidates
* Interviewed Candidates
* Offered Candidates
* Joined Candidates
* Time to Hire

#### Visualizations

* Hiring Funnel (Funnel Chart)
* Monthly Applications Trend (Line Chart)
* Source of Hire Performance (Clustered Bar Chart)
* Hiring by Role (Clustered Column Chart)

---

### 2️⃣ Recruiter Performance

Evaluates recruiter productivity and effectiveness.

#### KPIs

* Total Hires
* Time to Hire
* Cost per Hire

#### Visualizations

* Recruiter Performance Summary (Table)
* Top Recruiters by Hires (Clustered Bar Chart)
* Hiring by Experience Level (Clustered Column Chart)
* Hiring by Region (Donut Chart)

---

### 3️⃣ Source & Cost Analysis

Analyzes recruitment sources and hiring efficiency.

#### KPIs

* Total Applicants
* Joined Candidates
* Cost per Hire

#### Visualizations

* Hires by Source (Clustered Bar Chart)
* Total Hiring Cost by Source (Clustered Column Chart)
* Cost vs Hiring Efficiency (Scatter Plot)
* Offer Acceptance by Source (Clustered Bar Chart)

---

## 🏗️ Data Model

Star Schema Design:

                       Calendar
                          |
                          |
    Jobs ───────────► Candidates ◄────────── Recruiters


This structure improves reporting performance and enables efficient filtering across dashboard pages.

---

## 🔍 Key Insights

* LinkedIn generated the highest number of applicants and hires.
* Senior recruiters achieved the highest hiring volume.
* Recruitment source effectiveness varies significantly across channels.
* Hiring cost and offer acceptance rates provide deeper insight into source efficiency.
* Funnel analysis highlights candidate drop-off at different hiring stages.
